Chapter 15 Output Module

This final tab in Quickomics is used to download the plots, tables and heatmap data saved during the analysis (Section 15.1), to save the settings of a session and restore them later (Section 15.2), and to help troubleshoot problems (Diagnostics, Section 15.3).

15.1 Download Plots and Tables

Plots can be downloaded here in high resolution, including for use in publications. Users can save different plots by clicking on “Save to Output” present on the top left corner of the plot during analysis and exploration of the datasets in all previous tabs. Upon clicking on the “Output” tab as seen in the image below, Users can see a list of plots that are available to download to their local machine. The checked plots are downloaded together as one PDF file with “Download PDF”, while “Download SVG” saves only the first selected plot. “Plot File Page Width” and “Plot File Page Height” set the page size of the files, and “Clear all saved plots” empties the list.

Tables and heatmap data can be saved in the same way. Tables saved with “Save to output”, for example the DEG data table, are listed under “Tables to Save” and are downloaded together as one Excel (.xlsx) file. Heatmap data saved with “Save GCT data file to output” in the Heatmap module (Chapter 6) or the WGCNA module (Chapter 9), or with the GCT buttons of the heatmaps in the Time Course Analysis module (Chapter 12), are listed under “GCT tables to Save” and are downloaded as GCT files, which can be opened in other tools such as Morpheus. In the example below, we saved the PCA plot, a volcano plot and a heatmap, the DEG data table, and the heatmap GCT file.

15.2 Save Session

“Save Session” saves the current settings of all tabs, such as the selected groups and samples, comparisons, cutoffs and plot options, so that the same analysis can be continued later. Click “Save Session”, then click “Download Session File” to download the settings as a file; the file name starts with the project ID, followed by the date and time, for example Mouse_microglia_RNA-Seq_20261105_124611.rds. To continue later, open the same project and upload the file under “Restore Session from File”; Quickomics then restores the settings of all tabs. A session file can only be restored in the project it was saved from. If another project is open, Quickomics names the project that the file was saved for and asks Users to open that project first. Only the settings are saved: plots and tables saved to the Output tab are not included in the session file, so they have to be saved again after the session is restored.

15.3 Diagnostics

The “Diagnostics” section at the bottom of the Output page helps to troubleshoot problems when running the application. “Log Level” (DEBUG, INFO, WARN or ERROR) sets how much detail the session writes to the server log; the change takes effect immediately and affects only the current session. “Session Location” shows which server container is serving the session; please quote it when reporting a problem, as it identifies the log file to look at.
