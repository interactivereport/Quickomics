Chapter 7 DEG Module

This section is designed to explore the differentially expressed genes (DEGs) and differentially expressed proteins (DEPs) in the dataset. The comparisons are defined by the User when they input the dataset. Please refer to our GitHub for more details on uploading datasets.

“DEG Counts” (Section 7.1) summarizes the number of DEGs/DEPs in each comparison. The “Volcano Plot (Static)” described in Section 7.2 and “Volcano Plot (Interactive)” described in Section 7.3 are ways to visualize each pair-wise comparison one by one. “DEGs in Two Comparisons” described in Section 7.4 is a novel way to visualize the similarities and differences in two comparisons. Finally, “Data Table” described in Section 7.5 displays a searchable table containing all genes and their fold changes and P values in each comparison.

7.1 DEG Counts

The DEG Counts tab provides a summary of the number of significantly changed genes for each comparison, separating Up- and Down-regulated genes. The genes are counted with the fold change and P value (or adjusted P value) cutoffs set in the left panel, and only the comparisons selected in the “Groups and Samples” module (Chapter 3) are listed. Clicking a comparison name opens its volcano plot, and the table can be downloaded by page or as a whole.

7.2 Volcano Plot (Static)

This plot reveals the differentially expressed genes provided in the input data file. By default, the Fold change Cutoff is set to 1.2 and the P value Cutoff is set to 0.01. Users have the option to change any of these parameters. For more advanced display options, they can set the “Show More Options” to “Yes” to customize other settings.

The red dots are indicative of all genes that pass the Fold Change and P value cutoff, while the green dots are indicative of genes that only pass the P value cutoff. By default, the DEGs with the largest fold changes are labeled, up to 50 genes. In the example below, we selected the 2mo_Hetvs2mo_WT comparison with the default parameters; 82 genes pass the cutoffs, 21 up- and 61 down-regulated.

“Label Genes” offers four choices: “DEGs” labels the top DEGs/DEPs, “None” shows no labels, “Upload” labels the genes entered in a list (as UniqueID, Gene.Name or Protein.ID), and “Geneset” labels the genes of a gene set chosen with the gene set search described in Section 1.1.

For demonstration purposes, we have changed the following attributes to highlight a few genes in this dataset. We kept the 2mo_Hetvs2mo_WT comparison and the default cutoffs. In the example below, we select an “Immune Response” dataset from the Molecular Signatures Database (MSigDB) to highlight the genes by adding labels to the volcano plot. As MSigDB contains only human gene lists and the demo dataset is from mouse, Quickomics matches the gene names without regard to upper or lower case, so that a human gene such as CFP matches the mouse gene Cfp. The genes of the selected gene set are listed in the box below the “Select Geneset” button, where genes can be added or removed. If the list contains more genes than the number set by “# of Genes to Label” (50 by default), only that many are labeled. The label color can be changed with “Gene Label Color”. Of the labeled immune genes, Cfp is among the most strongly down-regulated genes, while most of the others are not significantly changed in 2mo Het microglia.

A set of genes can also be shown in a different color, in addition to the labeled DEGs. In the example below, we kept the default settings, so the top DEGs of 2mo_Hetvs2mo_WT are labeled in blue. We then set “Highlight a Set of Genes in a Different Color?” to “Yes” and pasted genes that are significantly changed in the 2yr_Hetvs2yr_WT comparison into “Enter Gene List to Highlight”, chose black as their color, and, for demonstration purposes, entered seven of them in the box below to label them: Cp, Acsf3, Birc5, Cdkl3, Mapk8, Lmnb1 and Gbgt1. Genes entered in this label box are always labeled. After clicking “Apply Highlight”, the highlighted genes are shown as black dots and the seven genes are labeled in black. None of them pass the cutoffs in 2mo_Hetvs2mo_WT, so the black dots are among the grey dots near the bottom of the plot. Genes can also be sent to the highlight list from the interactive volcano plot (Section 7.3).

Under “Show More Options”, “Max abs(log2FC) in plot” and “Max -log10(Stat Value) in plot” limit the range of the axes (0 shows the full range), and the label font size, legend font size and legend position can be changed. “Rasterize plot” draws the dots as a bitmap image while keeping the text and axes sharp, which makes saved plots smaller when there are many genes.

7.3 Volcano Plot (Interactive)

This next sub-tab is a very similar visualization as the previous one (7.2 Volcano Plot (Static)) with an additional capability where users can hover over a particular dot/gene on the plot to see the gene name and ID. This plot has a few attributes that can be changed, and in the example below we have used the same cutoffs as in Section 7.2.

Genes can also be selected directly on the plot. Choose the lasso or box-select tool in the toolbar at the top right of the plot and circle a group of dots; the number of selected genes and a table of these genes (with their logFC, P value and adjusted P value) appear below the plot, and the table can be downloaded as CSV or Excel. Double-clicking the plot clears the selection. Clicking “Send Selected Genes to Highlight List” copies the selected genes to the highlight list of the static volcano plot (Section 7.2), where they can be shown in a different color after clicking “Apply Highlight”. In the example below, 76 strongly down-regulated genes in 2mo_KOvs2mo_WT were selected.

7.4 DEGs in Two Comparisons

This next tab helps with identifying DEGs/DEPs that follow a similar trend in two comparisons. Gyoneva et al., 2019, the source of this demo dataset, report that the genes differentially expressed in Cx3cr1 KO microglia in the 2mo KO are quite different from WT, while the differences from WT are smaller for the 1yr KO and 2yr KO, and the two older ages are similar to each other. We have plotted out the following comparisons that illustrate this conclusion.

2mo_KOvs2mo_WT vs 1yr_KOvs1yr_WT has a low correlation score of 0.211. There are many genes that are colored orange, meaning those genes were significant in 2mo_KOvs2mo_WT (Y axis) but not in 1yr_KOvs1yr_WT (X axis). Genes significant in both comparisons are blue, genes significant only in the X axis comparison are green, and the other genes are grey. The dot size shows the smaller of the two P values, and the correlation score in the title is the Pearson correlation of the log2 fold changes, shown with its P value.

Similarly, we changed the X axis to 2yr_KOvs2yr_WT to compare to 2mo_KOvs2mo_WT, and it shows a very similar plot with a low correlation score of 0.178.

Next, we changed the Y axis comparison to 1yr_KOvs1yr_WT comparing it to 2yr_KOvs2yr_WT on the X axis. This plot has a higher correlation score of 0.348 than the previous one, suggesting that these two comparisons are more similar. These comparisons represent additional insights supported by statistical analyses that were gained from the data and were not available in the original manuscript by Gyoneva et al.

Under “Show More Options”, “Color DEGs using dot color?” sets whether the gene labels take the color of their dots (“Yes”) or are all drawn in one color (“No”). “Make X and Y scale the same?” (“Yes” by default) gives both axes the same log2 fold change range, so that points on the diagonal have equal changes in the two comparisons; with “No”, each axis fits its own comparison.

7.5 Data Table

This tab lets the users view the DEGs/DEPs in a tabular format with a searchable feature. Users can sort and search the table, download the current page as CSV or Excel, print it, or save the whole table with “Save to output”.
